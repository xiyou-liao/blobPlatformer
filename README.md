# BLOB VOYAGE

**Help Blob get home!**

## Goal
To pass each level, Blob must obtain the key and go through the door.

Beware the monsters and *plan your movements carefully.*

## Movement Controls
- **A:** Move left
- **D:** Move right
- **W:** Jump

## Game Navigation
- **1:** Skip to Level 1
- **2:** Skip to Level 2
- **3:** Skip to Level 3
- **Q:** Quit game
